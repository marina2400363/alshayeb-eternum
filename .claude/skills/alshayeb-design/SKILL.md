# ALSHAYEB EXPERIENCE — Design Skill

Use this skill whenever designing, reviewing, or implementing UI for ALSHAYEB EXPERIENCE.

## Brand Direction

ALSHAYEB is an experience brand, not a SaaS product and not a corporate event company.

The visual feeling must be:

- premium
- cinematic
- dark
- bold
- youthful
- immersive
- editorial
- experimental
- nightlife-aware
- highly polished

Avoid:

- generic SaaS dashboards
- Bootstrap-looking layouts
- corporate UI
- cheap club aesthetics
- random neon
- excessive gradients
- childish styling
- generic AI-looking cards
- default component-library appearance

## Design Philosophy

Concept before decoration.

Large visual moments are preferred over many small decorative elements.

Use strong typography, photography, scale, negative space, controlled contrast and purposeful motion.

Every screen should feel part of one continuous ALSHAYEB world.

## Public Experience

The public-facing website should feel more like an interactive digital experience than a registration portal.

The sequence is:

Hero
→ ALSHAYEB Experiences
→ cinematic card journey
→ Enter Your Experience
→ functional customer flow

Do not expose forms immediately on the landing screen.

## Functional UI

Registration, Customer Area and Payment UI must retain the same design language while becoming clearer and calmer.

Functionality must remain obvious.

Never sacrifice usability for visual effects.

## Responsive

Desktop can be cinematic and spatial.

Mobile must remain intentional, not merely a scaled-down desktop layout.

Recompose layouts where needed.

## Existing Backend

Do not redesign backend architecture while working on visual tasks.

Preserve existing Marina and Sandra API contracts unless a genuine blocker is discovered.
